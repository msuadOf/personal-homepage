# Moved: Yifan Bai · Personal Homepage

The homepage now lives in the [resume-msuad repository](https://github.com/msuadOf/resume-msuad). Visit the [English site](https://blog.msuad.top/resume-msuad/) or the [Chinese site](https://blog.msuad.top/resume-msuad/zh/). This repository is retained as an archive of the initial standalone version.

A bilingual, static personal website for GitHub Pages. The default page is in English, and the Chinese version is at [`zh/index.html`](zh/index.html). Both pages share [`styles.css`](styles.css) and need no build step.

The information structure was inspired by [Leonid Keselman's personal website](https://github.com/leonidk/leonidk.github.io). The HTML, CSS, and content here were written for this site.

## Local preview

Run `python3 -m http.server 8000` in this directory, then open `http://localhost:8000/`.
